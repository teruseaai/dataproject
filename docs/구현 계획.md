## 2. 파일 구성

| 파일 | 하는 일 |
|---|---|
| `streamlit_app.py` | 앱의 시작점. 로그인과 화면 연결 |
| `views.py` | 팀 목록, 지원, 투표 화면 |
| `admin_views.py` | 관리자 화면(명단 올리기, 마감, AI 배정, 확정) |
| `service.py` | 지원, 투표, 마감, 확정 같은 규칙과 DB 처리 |
| `rules.py` | 배정안 검사 다섯 가지. DB를 쓰지 않는 순수한 계산 |
| `solver.py` | 모든 경우를 따져 규칙을 지키는 배정을 찾기. 불가능할 때의 이유 설명 |
| `ai.py` | 오픈라우터 호출, 모델마다 120초 제한, 3개 모델 넘어가기 |
| `assign.py` | AI에게 보낼 글과 답을 배정안으로 바꾸기 |
| `config.py` | 1, 2, 3차 모델 이름 |
| `accounts.py` | 관리자 계정 만들기, 로그인 |
| `auth.py` | 비밀번호 해시 |
| `db.py` | DB 연결 |
| `roster.py` | 명단 CSV 읽기 |
| `schema.sql` | 테이블 만드는 SQL |

## 3. 만드는 방법

- 한 번에 한 가지씩 만들고, 만들 때마다 직접 눌러 보거나 작은 시험 코드로 확인했다.
- DB를 쓰지 않는 계산(`rules.py`, `solver.py`, `assign.py`)은 별도 파일로 두어 가짜 데이터로 시험했다.
- 오픈라우터를 실제로 부르는 시험은 하루 50회 한도 때문에 최소한으로 했고, 모델 넘어가기는 가짜 모델로 시험했다.
- 키는 `.env`와 Streamlit Secrets에만 두고, 화면에 출력하지 않는다.
